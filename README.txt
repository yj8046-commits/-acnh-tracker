내 동숲 도감 v1

기능
- 남반구/북반구 전환
- 1~12월 출현 생물 필터
- 현재 시간 출현 중 필터
- 이번 달이 마지막인 생물 필터
- 물고기/곤충/해산물 체크
- 미술품 43종 체크 + 가품 존재 여부
- 남은 것만 / 완료만 보기
- 체크 데이터 브라우저 자동 저장
- JSON 백업/복원

사용
1) 웹서버(HTTPS)에 이 폴더의 파일 4개를 그대로 올립니다.
2) iPhone Safari에서 index.html 주소를 엽니다.
3) 공유 → 홈 화면에 추가를 누르면 앱처럼 실행할 수 있습니다.

주의
- Nintendo Switch 세이브와 자동 연동되는 앱은 아닙니다. 공개 API로 개인 Critterpedia/박물관 상태를 읽어올 수 없기 때문에 최초 체크는 직접 해야 합니다.
- 생물/미술품 기본 데이터는 ACNHAPI GitHub 데이터를 사용하며, 처음 실행 시 인터넷이 필요합니다. 이후 데이터는 브라우저에 캐시됩니다.
